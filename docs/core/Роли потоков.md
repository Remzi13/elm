# Роли потоков

Файлы: `core/Threading.hpp`, `core/Debug.hpp`. За потоками с фиксированной обязанностью
закрепляется роль `core::ThreadRole`: `Update` или `Render`.

```cpp
#include "core/Threading.hpp"

core::registerThread(core::ThreadRole::Update);   // в начале EngineApp::Init
core::registerThread(core::ThreadRole::Render);   // в начале функции render-потока
core::unregisterThread(core::ThreadRole::Render); // при выходе
```

Проверку можно ставить в свой код:

```cpp
#include "core/Debug.hpp"

void MySystem::Tick() {
    ELM_ASSERT_THREAD(Update);   // в release-сборке ничего не делает
}
```

`isThread(role)` возвращает `true` в двух случаях: если вызывающий поток держит роль или
если роль ещё никто не зарегистрировал. Пока роли не назначены, проверка не мешает.

## Где используется

`RenderSystem::BeginFrame`/`SubmitFrame` (`Update`), `RenderNextFrame` (`Render`). См.
[[Правила потоков рендера]].
