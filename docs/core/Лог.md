# Лог

Файлы: `core/Log.hpp`, `core/Log.cpp`. Сообщение пишется макросом с категорией (`log::Category`)
и источником:

```cpp
LOG_MESSAGE(log::Category::Core, "Engine", "Project %s opened", name.c_str());
WARNING_MESSAGE(...); ERROR_MESSAGE(...); FATAL_ERROR_MESSAGE(...);
```

Ошибки `EngineResult` попадают в лог сами: их создаёт `MakeUnexpected` (`core/Unexpected.hpp`).

## Куда идут сообщения

Каждое сообщение уходит во все включённые выводы сразу, из любого потока, под одним мьютексом:

- **Хранилище** — последние `getMaxMessages()` сообщений (по умолчанию 5000). Окно Log редактора
  забирает их `takeMessages()`.
- **Консоль** — stdout для Info, stderr для остальных. Включается при сборке опцией CMake
  `ELM_LOG_CONSOLE` (по умолчанию `ON`).
- **Файл** — включается при запуске, см. ниже.

Строка одинакова в консоли и в файле:

```
14:03:27.512 [WARNING] [CORE] [Log] Cannot open the log file Logs/game.log (src/core/Log.cpp:312)
```

## Лог-файл

Настройка `Core/Log/File` в `.settings` (`log::FileSetting`): путь к файлу, относительный — от папки
файла `.settings`. Пустая строка (по умолчанию) — файла нет. `Engine::Init` применяет её сразу
после чтения настроек (`log::applySettings`), так что в файл попадает весь запуск.

- Файл начинается строкой `Log started <дата время>`, за ней — сообщения, которые хранилище ещё
  держит. Сообщения до открытия файла не теряются.
- Строки пишутся пачкой, а не по одной: они копятся в буфере и уходят на диск одной записью
  - раз в кадр (`log::flushFile()` в конце кадра `Engine::Run`);
  - когда в буфере набралось 64 КБ (`FileBufferSize`), даже посреди кадра;
  - сразу, если пришло предупреждение или ошибка — вместе со всеми строками перед ним;
  - при `log::closeFile()`, смене файла и выходе из программы.

  При падении могут пропасть только Info-строки текущего кадра; предупреждения и ошибки уже на диске.
- Файл прошлого запуска с тем же именем переименовывается в `<имя>.prev<расширение>`
  (`Logs/game.log` → `Logs/game.prev.log`). Хранятся два запуска: текущий и прошлый.
- Не удалось открыть (нет прав на папку) — предупреждение в лог, работа идёт без файла.

Собранная игра пишет лог по умолчанию: `ProjectBuilder` кладёт в её `.settings`
`Core/Log/File = "Logs/<Имя>.log"` ([[Проекты#Сборка]]). Чтобы выключить, очистите строку.

Из кода: `log::openFile(path)`, `log::flushFile()` и `log::closeFile()`.
