# Рендер

Обзорная заметка (MOC) по `src/render`. Как всё устроено целиком, описано в
[[Архитектура рендера]]. Ниже все заметки по темам.

## Основы
- [[Архитектура рендера]] — потоки данных и слои каталогов
- [[Правила потоков рендера]] — что из какого потока можно вызывать
- [[Главный цикл]] — инициализация, цикл, завершение

## Ресурсы (update-сторона, любой поток)
- [[Хэндлы]] — типизированные хэндлы с поколениями
- [[RenderResources]] — API создания и удаления ресурсов
- [[Текстуры]]
- [[Меши и инстансинг]]
- [[Буферы]]
- [[Загрузка ресурсов в фоне]]
- [[Время жизни ресурсов]]

## Кадр (update → render)
- [[FrameWriter]] — запись кадра на update-стороне
- [[FrameSnapshot]] — что лежит в кадре и как добавить свои данные
- [[FrameRing]] — передача кадров между потоками
- [[ViewPort]] — цель 3D-вида и вывод текстур в ImGui
- [[Кадр на render-потоке]] — что происходит после `SubmitFrame`

## Отрисовка (render-сторона)
- [[Фичи]] — `IRenderFeature`, `RenderPipeline`
- [[RenderGraph]] — пасы, зависимости, барьеры
- [[Ресурсы графа]] — transient, import, surface, blackboard
- [[CommandList]] — команды отрисовки
- [[UploadAllocator]] — память кадра для вершин и констант
- [[Шейдеры и пайплайны]]
- [[Параллельная запись]]
- [[Пример HighlightPass]] — новая фича целиком
