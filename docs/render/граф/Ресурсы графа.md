# Ресурсы графа

`RGTexture` — виртуальная текстура одного кадра [[RenderGraph]]. Бывает трёх видов.

## Transient

Живёт в пределах кадра. Между кадрами её переиспользует `TransientTexturePool`, а текстуры,
не использованные 8 кадров, удаляются. Пример — глубина `ScenePass`.

```cpp
RGTexture bloom = builder.CreateTexture("Bloom", desc);
```

## Импорт долгоживущей текстуры

Текстура, созданная через [[RenderResources]] (например, цвет [[ViewPort]]):

```cpp
TextureDesc desc;
backend.GetTextureDesc(frame.sceneView.colorTarget, desc);   // актуальный размер после ресайза
RGTexture scene = graph.ImportTexture("SceneColor", frame.sceneView.colorTarget, desc);
```

Запись в импортированную текстуру не даёт отсечь пас.

## Backbuffer окна

```cpp
RGTexture screen = graph.ImportSurface("Main", render::MainSurface, frame.backbufferSize);
```

Переходами surface управляет бэкенд. Запись в surface тоже защищает пас от отсечения.

## Blackboard

Между [[Фичи|фичами]] ресурсы передаются через `FrameBlackboard`
(`render/passes/IRenderFeature.hpp`). Сейчас в нём `sceneViews`: на каждый нарисованный 3D-вид
`SceneViewTargets` с индексом вида в `FrameSnapshot::sceneViews`, его цветом и глубиной. Глубина
временная, но живёт до конца кадра, поэтому пас поверх сцены может проверять по ней свою
геометрию. Добавляйте свои поля.

```cpp
// ScenePass::Setup
blackboard.sceneViews.push_back({ viewIndex, sceneColor, scene.depth });

// Пас поверх сцены: пишет в те же цели после ScenePass, глубину не очищает
data.color = builder.WriteColor(view.color);
data.depth = builder.WriteDepth(view.depth);

// OverlayPass::Setup: Read() даёт порядок "после сцены" и переход в ShaderResource
for (const auto& sceneView : blackboard.sceneViews)
    builder.Read(sceneView.color);
```

Цепочка «писатель → читатель» задаёт порядок пасов. Ничего больше для этого не нужно.

## В execute

```cpp
TextureHandle h            = context.Resolve(data.color);
const TextureDesc& d       = context.GetDesc(data.color);
rhi::ColorAttachment color = context.ColorTarget(data.color, /*clear*/ true, clearColor);
rhi::DepthAttachment depth = context.DepthTarget(data.depth, /*clear*/ true, 1.0f);
```
