# Шейдеры и пайплайны

Описания: `render/api/PipelineDesc.hpp`. Шейдеры и пайплайны создаются в `Init`
[[Фичи|фичи]] на render-потоке через `rhi::IRenderBackend`. Шейдер — это HLSL из каталога
`shaders/`, точка входа `main`.

```cpp
const auto vs = backend.CreateShader({ "Mesh VS", ShaderStage::Vertex, "mesh.vert.hlsl", {} });

ShaderDesc psDesc { "Tint PS", ShaderStage::Pixel, "tint.frag.hlsl", {} };
psDesc.macros.push_back({ "USE_TINT", "1" });
const auto ps = backend.CreateShader(psDesc);

PipelineDesc desc;
desc.name         = "Tint";
desc.vertexShader = vs;
desc.pixelShader  = ps;
desc.vertexLayout = {                       // { location, bufferSlot, format, perInstance }
    { 0, 0, VertexFormat::Float3, false },
    { 1, 0, VertexFormat::Float3, false },
    { 2, 0, VertexFormat::Float2, false },
};
desc.colorFormat = TextureFormat::RGBA8_UNORM_SRGB;  // должен совпадать с форматом таргета
desc.depthFormat = TextureFormat::D32_FLOAT;         // Unknown — без depth
desc.blend       = BlendMode::AlphaBlend;            // Opaque / PremultipliedAlpha / AlphaBlend
desc.depthTest   = true;
desc.bindings = {
    { "Constants", ShaderStage::Vertex, BindingType::Constants, sizeof(Constants) }, // slot 0
    { "g_Texture", ShaderStage::Pixel,  BindingType::Texture,   0 },                 // slot 1
};
desc.samplers = { { "g_Texture", ShaderStage::Pixel } };  // linear clamp -> "g_Texture_sampler"

m_pipeline = backend.CreatePipeline(desc);   // невалидный хэндл = ошибка, текст уже в логе
```

## Слоты

Индекс в `bindings` — это слот для `SetConstants`/`BindTexture` в [[CommandList]]. Имя
binding'а должно совпадать с именем ресурса в HLSL (`cbuffer Constants`, `Texture2D g_Texture`).

## Удаление

```cpp
void MyFeature::Release(rhi::IRenderBackend& backend) { backend.DestroyPipeline(m_pipeline); }
```
