# Параллельная запись

Command list'ы записываются на воркерах [[JobSystem]]. Трансляция в бэкенд при этом
последовательная ([[Ограничения рендера]]). Оба вида параллельности включены по умолчанию
(`RenderPipeline::SetParallelRecording`).

## Между пасами

Пасы одного уровня [[RenderGraph]] записываются одновременно. Пример — `OverlayPass`: на
каждое UI-окно добавляется свой пас, они друг от друга не зависят.

## Внутри паса: RecordParallel

`PassContext::RecordParallel` режет работу на батчи. Каждый батч пишется в свой
[[CommandList]]. Списки отправляются сразу после основного списка паса, в порядке батчей.

```cpp
[pipeline](const Data& data, PassContext& context) {
    const auto& items = context.Frame().drawItems;
    constexpr float clearColor[4] = { 0.1f, 0.1f, 0.1f, 1.0f };

    // Основной список: только очистка таргетов
    auto& cmd = context.Commands();
    cmd.BeginRenderPass(context.ColorTarget(data.color, true, clearColor), context.DepthTarget(data.depth, true));
    cmd.EndRenderPass();

    // Значения для батчей готовятся заранее; лямбда батча берёт их по ссылке,
    // это безопасно: RecordParallel возвращается только после всех батчей
    const auto color = context.ColorTarget(data.color, false, clearColor);
    const auto depth = context.DepthTarget(data.depth, false);
    const auto constants = context.Uploads().Upload(rhi::UploadArena::Constants, &cameraConstants, 1);

    context.RecordParallel(items.size(), /*batchSize*/ 2048,
        [&](rhi::CommandList& list, size_t begin, size_t end) {
            // Каждый список самодостаточен: таргеты, пайплайн и константы ставятся заново
            list.BeginRenderPass(color, depth);
            list.SetPipeline(pipeline);
            list.SetConstants(0, constants);
            RecordItems(items, begin, end, list, context.Uploads());   // UploadAllocator lock-free
            list.EndRenderPass();
        });
}
```

`ScenePass` (`render/passes/ScenePass.cpp`) делает так же: начиная с 4096 инстансов он режет
сцену на батчи по 4 draw-группы.

## Правила для кода на воркере

- Можно трогать только данные паса, кадр через `context.Frame()` (только чтение) и
  `context.Uploads()` ([[UploadAllocator]]).
- Нельзя трогать [[RenderResources]], бэкенд и состояние фичи, изменяемое в других местах.
- Мелкие задачи делить невыгодно: накладные расходы больше выигрыша.

Сколько списков записано на воркерах, показывает окно Profiler ([[Отладка рендера]]).
