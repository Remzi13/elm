# Фичи

Фича (`render/passes/IRenderFeature.hpp`) владеет своими пайплайнами и каждый кадр добавляет
свои пасы в [[RenderGraph]].

```cpp
class IRenderFeature {
public:
    virtual StringView GetName() const = 0;
    virtual bool Init(rhi::IRenderBackend& backend) = 0;      // один раз: шейдеры, пайплайны
    virtual void Release(rhi::IRenderBackend& backend) = 0;
    virtual void Setup(RenderGraph& graph, const FrameSnapshot& frame,
        const rhi::IRenderBackend& backend, FrameBlackboard& blackboard) = 0;   // каждый кадр
};
```

- В `Init` создаются шейдеры и пайплайны ([[Шейдеры и пайплайны]]).
- `Setup` только **объявляет** пасы, команды в нём не записываются.
- Через `FrameBlackboard` фичи передают друг другу ресурсы графа ([[Ресурсы графа#Blackboard]]).

## Регистрация в RenderPipeline

`RenderPipeline` (`render/RenderPipeline.cpp`) хранит список фич. Каждый кадр он строит из
них граф, компилирует его и выполняет. Порядок регистрации задаёт порядок объявления пасов:

```cpp
// RenderPipeline::Init
m_features.push_back(MakeUnique<ScenePass>());
m_features.push_back(MakeUnique<HighlightPass>());   // своя фича
m_features.push_back(MakeUnique<OverlayPass>());
```

Пример регистрации своей фичи — [[Пример HighlightPass]].

## Существующие фичи

| Фича | Что делает |
|---|---|
| `ScenePass` | рисует `drawItems` в цвет 3D-вида ([[ViewPort]]) с transient-глубиной; большие сцены пишет батчами ([[Параллельная запись]]) |
| `OverlayPass` | рисует UI: по одному пасу на каждое окно (основное и дополнительные); читает цвет сцены |
