# FrameRing

Файл: `render/frame/FrameRing.hpp`. Передаёт [[FrameSnapshot]] от update к render. В нём три
слота:

```
render рисует N  │  N+1 ждёт в очереди  │  update собирает N+2
```

- Update получает свободный слот в `RenderSystem::BeginFrame()`. Ждёт, **только** если все
  три слота заняты, то есть update ушёл вперёд на два кадра.
- Render забирает кадры строго по порядку, ни один не пропускается. Поэтому команды ресурсов
  внутри кадров выполняются все и в правильном порядке ([[Время жизни ресурсов]]).
- `RenderSystem::StopRendering()` закрывает кольцо. После этого `BeginFrame` возвращает
  невалидный [[FrameWriter]], а `RenderNextFrame` возвращает `false`.

Текущее отставание рендера (в кадрах) показывает окно Profiler ([[Отладка рендера]]).
