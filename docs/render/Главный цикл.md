# Главный цикл

Минимальная схема, по которой работает `EngineApp` (`src/EngineApp.cpp`).

```cpp
#include "core/JobSystem.hpp"
#include "core/Threading.hpp"
#include "platform/Window.hpp"
#include "render/RenderSystem.hpp"

platform::Window window;
render::RenderSystem renderSystem;

// --- инициализация (update-поток) ---
core::registerThread(core::ThreadRole::Update);
core::JobSystem::Get().Init();                         // воркеры для параллельной записи

if (auto r = window.Create({ 1280, 720 }, "Engine"); !r) { /* ошибка */ }
if (auto r = renderSystem.Init(window.GetNativeWindow(), window.GetFramebufferSize()); !r) { /* ошибка */ }

// --- render-поток ---
std::thread renderThread([&] {
    core::registerThread(core::ThreadRole::Render);
    render::RenderedFrameInfo info;
    while (renderSystem.RenderNextFrame(info)) {
        // info.releasedSurfaceCount: сколько UI-окон render-поток отпустил в этом кадре
    }
});

// --- главный цикл (update-поток) ---
while (!window.ShouldClose()) {
    PollInputAndUpdateGame();

    auto frame = renderSystem.BeginFrame();            // ждёт, только если render отстал на 2 кадра
    if (!frame)
        break;                                         // рендер остановлен

    frame.SetBackbufferSize(window.GetFramebufferSize());
    BuildUi(frame.Overlay());
    FillScene(frame);                                  // см. FrameWriter
    renderSystem.SubmitFrame(frame);                   // кадр + накопленные команды ресурсов
}

// --- завершение ---
renderSystem.StopRendering();                          // RenderNextFrame вернёт false
renderThread.join();
// удалить RAII-ресурсы (Texture, Mesh, ViewPort) до Shutdown
renderSystem.Shutdown();
window.Destroy();
core::JobSystem::Get().Shutdown();
```

## Детали

- Что делать с `frame`, описано в [[FrameWriter]].
- Почему `BeginFrame` может ждать, объясняет [[FrameRing]].
- Что происходит на render-потоке, описано в [[Кадр на render-потоке]].
- Ресурсы до `Shutdown` нужно удалить: см. [[Время жизни ресурсов]].
- Если окно свёрнуто, `GetFramebufferSize()` возвращает пустой размер. Тогда `SubmitFrame`
  оставляет последний валидный.
