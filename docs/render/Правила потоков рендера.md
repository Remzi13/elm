# Правила потоков рендера

| Что | Из какого потока |
|---|---|
| `Render::Resources()`, все методы [[RenderResources]], RAII `Texture`/`Mesh` | любой |
| `Render::Init`, `Shutdown` | update, render-поток остановлен |
| `Render::BeginFrame`, `SubmitFrame`, `StopRendering`, `GetSize` | update |
| [[FrameWriter]] | поток, который его получил (update) |
| `Render::RenderNextFrame` | render |
| `Render::GetRenderStats`, `GetMemAllocated` | любой |
| `IRenderFeature::Init/Release/Setup`, `IRenderBackend::*` | render |
| Execute-лямбда паса (`PassContext`, [[CommandList]]) | render **или воркер** ([[Параллельная запись]]) |

## Почему draw-API нельзя вызвать из update

`PassBuilder`, `PassContext` и command list'ы пасов создаёт только [[RenderGraph]], их
конструкторы закрыты. Получить эти объекты можно только внутри паса.

## Проверки в debug

`BeginFrame`/`SubmitFrame` проверяют, что их вызывает поток с ролью `Update`, а
`RenderNextFrame` — поток с ролью `Render`. Механизм описан в [[Роли потоков]].
