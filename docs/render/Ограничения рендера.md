# Ограничения рендера

Текущие ограничения. Это кандидаты на доработку.

- **Топология и индексы.** Топология примитивов только `TriangleList`, индексы только
  32-битные ([[CommandList]]).
- **Одна текстура на пайплайн.** В пайплайне не больше одного binding'а типа `Texture`.
  Бэкенд кэширует один SRB на подключённую текстуру. Constants-буферов может быть несколько
  ([[Шейдеры и пайплайны]]).
- **Шейдеры и пайплайны только на render-потоке** (`IRenderFeature::Init`). Через
  [[RenderResources]] их не создать.
- **Фиксированные форматы 3D-вида.** Цвет всегда `RGBA8_UNORM_SRGB`, глубина `D32_FLOAT`.
  Форматы зашиты в `ScenePass` ([[ViewPort]]).
- **Последовательная трансляция.** Command list'ы транслируются в Diligent последовательно,
  на immediate context. Параллельно идёт только запись ([[Параллельная запись]]). Перевод на
  deferred contexts не потребует менять API выше бэкенда ([[Бэкенды]]).
- **Фиксированный объём upload-памяти.** Одна арена на кадр фиксированного размера. При
  переполнении draw'ы пропускаются с ошибкой в логе ([[UploadAllocator]]).
- **Фичи регистрируются в коде.** Порядок задаётся вручную в `RenderPipeline::Init`
  ([[Фичи]]).
