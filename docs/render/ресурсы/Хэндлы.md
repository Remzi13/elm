# Хэндлы

Файл: `render/api/Handles.hpp`. Все ресурсы адресуются типизированными хэндлами:

```cpp
render::TextureHandle  texture;   // Handle<TextureTag>
render::MeshHandle     mesh;
render::BufferHandle   buffer;
render::ShaderHandle   shader;    // только render-поток
render::PipelineHandle pipeline;  // только render-поток
render::SurfaceId      surface;   // 0 = MainSurface, остальные — UI-окна
```

Шейдеры и пайплайны создаются только на render-потоке ([[Шейдеры и пайплайны]]).

## Устройство

- Хэндл занимает 32 бита: 24 бита на индекс слота и 8 бит на поколение. Нулевое значение
  невалидно.
- Слоты на update-стороне выделяет потокобезопасный `HandleAllocator`. Бэкенд хранит объекты
  в `ResourceRegistry`: это плотный массив, поиск по хэндлу работает за O(1).
- После удаления слот переиспользуется с новым поколением. Старый хэндл перестаёт находиться
  в реестре, и обращение к нему тихо пропускается ([[Время жизни ресурсов]]).

```cpp
if (texture)                       // то же, что texture.IsValid()
    uint32_t raw = texture.Raw();  // например, для упаковки в ImTextureID
auto same = render::TextureHandle::FromRaw(raw);
```

Как сырое значение используется для `ImTextureID`, описано в [[ViewPort]].

Хэндлы transient-текстур, которые создаёт бэкенд по запросу графа ([[Ресурсы графа]]), не
пересекаются с хэндлами update-стороны: их отличает старший бит индекса.
