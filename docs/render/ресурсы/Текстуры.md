# Текстуры

Описание текстуры: `render::TextureDesc` в `render/api/ResourceDesc.hpp`.

## Создание и загрузка пикселей

```cpp
#include "render/api/RenderResources.hpp"

render::TextureDesc desc;
desc.name      = "Noise";
desc.width     = 256;
desc.height    = 256;
desc.format    = render::TextureFormat::RGBA8_UNORM;
desc.usage     = render::ResourceUsage::Default;
desc.bindFlags = render::TextureBind::ShaderResource;

// RAII: деструктор сам отправит DestroyTexture
render::Texture noise(resources, desc);

// Данные копируются в команду, буфер можно сразу переиспользовать
render::TextureData pixels;
pixels.stride = 256 * 4;                 // байт в строке, 0 = плотно упакованы (width * 4)
pixels.data.resize(pixels.stride * 256);
FillNoise(pixels.data);
noise.Update(std::move(pixels));
```

## Ресайз

Ресайз пересоздаёт хранилище текстуры, содержимое теряется. Если размер не изменился, вызов
ничего не делает. Так работает [[ViewPort]].

```cpp
noise.Resize(512, 512);
```

## Без RAII

```cpp
render::TextureHandle h = resources.CreateTexture(desc);
resources.UpdateTexture(h, std::move(pixels));
resources.ResizeTexture(h, 512, 512);
resources.DestroyTexture(h);
```

## Форматы и флаги

| `TextureFormat` | |
|---|---|
| `RGBA8_UNORM`, `RGBA8_UNORM_SRGB`, `BGRA8_UNORM`, `BGRA8_UNORM_SRGB` | цвет |
| `R32_FLOAT` | данные |
| `D32_FLOAT`, `D24_UNORM_S8_UINT` | глубина |

`TextureBind::ShaderResource | RenderTarget | DepthStencil`. Текстура, в которую рисует пас,
должна иметь флаг `RenderTarget`. Как её подключить к графу, описано в [[Ресурсы графа]].

## Показать в UI

```cpp
ImGui::Image(ImGuiSystem::ToTextureId(noise.GetHandle()), ImVec2(256, 256));
```

Подробнее в [[ViewPort]].
