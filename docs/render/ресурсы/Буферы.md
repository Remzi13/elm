# Буферы

Долгоживущие GPU-буферы создаются через [[RenderResources]].

```cpp
render::BufferDesc desc { "Params", render::BufferType::Uniform, 256, render::ResourceUsage::Default };
Vector<uint8_t> initial(256, 0);
render::BufferHandle params = resources.CreateBuffer(desc, std::move(initial));

resources.UpdateBuffer(params, /*offset*/ 0, std::move(bytes));
resources.DestroyBuffer(params);
```

`BufferType`: `Vertex`, `Index`, `Uniform`.

В [[CommandList]] буфер подключается так: `rhi::BufferSource::FromBuffer(params, offset)`.

> [!tip] Данные, которые меняются каждый кадр
> Для данных, которые меняются каждый кадр (инстансы, константы, геометрия UI), отдельный
> буфер не нужен. Используйте [[UploadAllocator]].
