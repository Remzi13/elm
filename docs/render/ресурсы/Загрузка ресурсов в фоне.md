# Загрузка ресурсов в фоне

[[RenderResources]] потокобезопасен, поэтому ресурсы можно грузить на воркерах [[JobSystem]].

```cpp
core::TaskGroup loads;
for (const auto& path : meshFiles) {
    loads.Run([&resources, &path, &out] {
        auto data = MakeShared<const MeshData>(LoadMesh(path));   // долго, на воркере
        render::MeshHandle handle = resources.CreateMesh(data);    // сразу валидный хэндл
        out.Publish(path, handle, data);                           // синхронизация — на вашей стороне
    });
}
loads.Wait();
```

Хэндл можно отдавать в [[FrameWriter]] сразу. Команда создания уходит со следующим
`SubmitFrame` и выполняется раньше, чем рисуется этот кадр ([[Кадр на render-потоке]]).

Если кадр с этим хэндлом уже отправлен, а команда создания ещё не дошла, отрисовка просто
пропустится. Падения не будет.
