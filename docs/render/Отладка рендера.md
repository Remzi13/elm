# Отладка рендера

## Окно Profiler

Показывает статистику последнего кадра:
- **Граф:** число пасов (и сколько отсечено), уровней, draw call'ов ([[RenderGraph]]).
- **Command list'ы:** сколько всего и сколько записано на воркерах ([[Параллельная запись]]).
- **Отставание:** на сколько кадров рендер отстаёт от update ([[FrameRing]]).

Программно то же самое отдаёт `renderSystem.GetRenderStats()` (любой поток).

## Флаги запуска

```bash
Engine.exe --scene 1 --instances 20000
```

Пресеты: 0 — Box, 1 — Wall & Grid, 2 — Rooms, 3 — Physics Sandbox. С большим `--instances`
включается батчевая запись `ScenePass`.

## Tracy

| Зоны | |
|---|---|
| `Render Frame`, `Resource Commands`, `Sort Draw Items`, `Present` | [[Кадр на render-потоке]] |
| `Render Graph Setup/Compile/Execute`, `Record Pass` (с именем паса), `Record Pass Batch`, `Backend Submit` | [[RenderGraph]] |
| `Wait For Free Frame Slot`, `Wait For Frame Snapshot` | [[FrameRing]] |

Потоки называются `Main Thread`, `Render Thread`, `Worker N`.

## Типовые проблемы

| Симптом | Где смотреть |
|---|---|
| Объект не рисуется | хэндл создан? ([[Время жизни ресурсов#Устаревший хэндл]]) Попал в `Draw`? ([[FrameWriter]]) |
| Слишком много draw call'ов | меш на каждый объект ([[Меши и инстансинг]]) |
| Пас пропал из графа | его результат никто не читает, пас отсечён ([[RenderGraph#Compile()]]) |
| Мусор или краш в execute | захват по ссылке в execute-лямбде ([[RenderGraph]]) |
| `ELM_ASSERT_THREAD` сработал | вызов не из того потока ([[Правила потоков рендера]]) |
| «Upload arena is full» в логе | слишком много данных за кадр ([[UploadAllocator]]) |
| Пайплайн не создался | лог `Render`: шейдер не найден или не скомпилировался ([[Шейдеры и пайплайны]]) |

Ошибки рендера пишутся в окно Log, категория `Render`.
