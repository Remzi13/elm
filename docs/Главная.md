# Документация движка

Точка входа в базу знаний. Папка `docs/` открывается в Obsidian как vault. Связи между
заметками видны в Graph view, переходы работают по wiki-ссылкам.

## Разделы

- [[Рендер]] — подсистема рендера: ресурсы, кадр, render graph, бэкенды
- [[JobSystem]] — пул потоков, `TaskGroup`, `parallelFor`
- [[Роли потоков]] — `ELM_ASSERT_THREAD` и регистрация потоков
- [[Скрипты на Lua]] — `ScriptSystem`, обёртка `lua::Module`/`lua::Class`, `NodeId`, скрипты сущностей
- [[Физика]] — `PhysicsSystem` на Jolt, компоненты `RigidBody` и `Collider`, триггеры, лучи
- [[Сцена]] — узлы, `NodeId`, компоненты и их типы, `SceneAsset`
- [[Файл сцены]] — формат `.scene`: узлы, модели, компоненты
- [[Редактор]] — Inspector, режимы Edit и Play

- Написать первую игру на Lua: [[Первая игра]] (Coin Rush: сцена, скрипты сущностей, редактор)
